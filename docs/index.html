kubeshelf

A zsh plugin for one-kubeconfig-per-cluster setups: switch clusters and namespaces, find which cluster has a namespace, and open k9s anywhere, with per-cluster tab-completion.

Pause anywhere to select and copy text. Recorded on fake clusters; k9s is shown with a stand-in screen. Keys: space play/pause, ←/→ seek.

Install (oh-my-zsh)

git clone https://github.com/pontatot/kubeshelf.git ~/.oh-my-zsh/custom/plugins/kubeshelf
~/.oh-my-zsh/custom/plugins/kubeshelf/install.sh
rm -f ~/.zcompdump* && exec zsh

Commands shown

kwhere payments                # which clusters have the 'payments' namespace
kwhere -p payments             # substring match: payments, payments-staging...
kswitch staging -n payments-staging   # default kubeconfig + namespace
kopen prod -n payments         # k9s on prod, directly in 'payments'
kopen -n monitoring            # find the cluster(s) first, pick one if several
